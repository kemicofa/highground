# Enemy appearance

For a clearer enemy list, open **Battlegrounds → Appearance** (`/hg enemy`), start the **Enemy list** preview, choose **Readable cards** and **Apply preset**. It enables the suggested-target card, hides rank numbers, and uses 44-pixel rows, 16-pixel health bars, stronger row backgrounds and brighter unseen names. **Compact bars** uses smaller bars in the docked compact layout; **Default** restores enemy styling. Presets replace enemy-row choices only when applied, keep the selected theme, and leave shared colors, textures, other addons' independent dimensions, and enemy count intact.

**Row background opacity** adds a theme-colored backing independent of panel fading (Frameless hides it). **Health bar opacity** adjusts the health fill; last-seen and unknown health remain progressively faded, and dead bars stay empty. **Unseen name brightness** controls names without a current observation. Under **Sizes and spacing**, adjust panel width (and therefore bar width), row height, **Bar thickness** (up to 28 pixels normally or 14 compact), and **Thin line height**. Normal and compact dimensions save separately. Rows grow as needed to keep names above thick bars. Color-picker Cancel restores the previous color, and Default restores the theme's default custom green.

Command equivalents: `/hg enemy preset readable|compact|default`, `/hg enemy style bar|fill|line`, `/hg enemy color shared|theme|class|faction|health|custom`, `/hg enemy custom HEX|default`, `/hg enemy texture shared|flat|blizzard|raid`, `/hg enemy height PX`, `/hg enemy line PX`, `/hg enemy row PX`, `/hg enemy width PX`, `/hg enemy background PCT`, `/hg enemy opacity PCT`, `/hg enemy names PCT`, and `/hg enemy hero on|off`. Choose **Custom color** before editing its swatch. All changes save with profiles; geometry waits until combat ends.
