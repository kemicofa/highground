## Description

````markdown
# Highground Bounties: standalone deprecated

This standalone addon no longer receives releases. Install [Highground](https://www.curseforge.com/projects/1749115) for this feature and future updates.

Highground includes Battlegrounds, Arena, Nearby, Bounties, Reputation and Macros. Enable the modules you want in **Highground → Addons** or WoW's AddOn List, then reload.

[Follow the migration instructions](https://github.com/kemicofa/highground/blob/main/addons/Highground/docs/getting-started.md#moving-from-a-standalone-addon). Fully quit WoW before removing the old standalone folder. Keep Highground, every HighgroundModule folder, both required data addons and your saved data, then restart.
````
