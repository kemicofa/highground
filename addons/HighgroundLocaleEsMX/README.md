# Highground language: Spanish (Latin America)

Highground's Spanish (Latin America) text (`esMX`), bundled with Highground. It loads only when you choose Spanish (Latin America) under **Shared preferences → General → Language**, or **Use game language** while the game runs in that language; otherwise it stays unloaded. Keep it beside Highground when installing the full download. Without it, Highground shows English and the language picker says why.

The catalog lives with the others in [libs/HighgroundKit/locale](../../libs/HighgroundKit/locale/esMX.lua); see [localization](../../docs/localization.md). [MIT](LICENSE).
