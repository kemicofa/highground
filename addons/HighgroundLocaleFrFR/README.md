# Highground language: French

Highground's French text (`frFR`), bundled with Highground. It loads only when you choose French under **Shared preferences → General → Language**, or **Use game language** while the game runs in that language; otherwise it stays unloaded. Keep it beside Highground when installing the full download. Without it, Highground shows English and the language picker says why.

The catalog lives with the others in [libs/HighgroundKit/locale](../../libs/HighgroundKit/locale/frFR.lua); see [localization](../../docs/localization.md). [MIT](../../LICENSE).
