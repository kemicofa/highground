# Highground Bounties module

Bundled switch for Bounties inside Highground. Enable or disable it in WoW’s AddOn List or Highground’s Addons page, then reload. Settings and records are preserved.

This folder controls the embedded implementation; shared library definitions remain in Highground. It is not the deprecated Highground Bounties standalone addon; this module is never published separately. Keep it beside Highground when installing the full bundle.
