HIGHGROUND — HORDE TWITCH STREAM OVERLAY

USE THIS FILE
Highground-Twitch-Banner-Horde-960.webm

960 x 144 pixels, 6-second loop, 25 fps, transparent exterior, no audio.
The crest spins and catches gold glints; the information stays still.
The banner has a 20:3 (6.67:1) aspect ratio.

OBS SETUP
1. Add a Media Source above the gameplay source.
2. Select the WebM as a Local File and enable Loop.
3. Leave hardware decoding off to preserve the transparent edges.
4. Use 960 x 144 on a 1920 x 1080 scene. Do not stretch it to fill the screen.
5. Put it at the bottom, on the opposite side to the webcam.

Suggested bottom-right placement on a 1080p scene:
Position X = 936, Y = 912. Size = 960 x 144.
This leaves 24 pixels at the right and bottom, and uses 6.7% of the frame.
See Placement-1080p.png for a diagram, with an example webcam position.
